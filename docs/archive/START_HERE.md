# Performance Powerhouse — Final Community Pack (24 Aug 2026)

This is the latest distribution bundle built from the QA-passed **V4 Community Edition** core.

## Start here
- `index.html` — full local-first Performance Powerhouse.
- `community-share.html` — dedicated community/share entry point.
- `?share=1` — privacy-safe mode for the main Powerhouse.
- `physics-intelligence/?share=1` — privacy-safe Physics Intelligence view.

## Why the core is still called V4
The app version and localStorage key are intentionally unchanged. Changing the schema/key only to rename the release would create avoidable migration risk. This bundle updates packaging and sharing entry points while preserving:

- `al_performance_powerhouse_v4`
- V3 → V4 migration
- `al_performance_powerhouse_physics_intelligence_v1`

## Governing academic loop
**Attempt → Mark → Diagnose → Repair → Closed-book reattempt → Fresh transfer → Delayed retest**

The product should reduce repeated mark loss, not increase tracking overhead.
