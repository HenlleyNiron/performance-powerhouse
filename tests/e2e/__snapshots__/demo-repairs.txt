SUBJECT LENS
Diagnose the right failure
The same wrong mark can require a different repair in each subject.
Physics · find the first wrong decision
Model/concept → equation choice → graph → sign/direction → algebra → units. Do not repair only the final arithmetic if the reasoning broke earlier.
Chemistry · memory vs reasoning
Forgotten condition/equation/observation = retrieval repair. Equilibrium/mechanism/calculation reasoning = conceptual or method repair.
Biology · retrieval vs marking production
Check factual recall, statement discrimination, exact terminology, sequence, diagrams and whether the required marking points were explicitly produced.
CLOSURE STANDARD
When may I call an error fixed?
1 · Repair
Fix the smallest actual cause.
2 · Reattempt
Close the source and reproduce the reasoning.
3 · Fresh transfer
Pass a different question testing the same idea.
4 · Delayed retest
Prove the correction survives after time has passed.
